# 提案の形（Discordで送るとき）

共同開発者から Jean=Summer へ、たすかReマインドの提案を送るときの形です。
Discord の本文は短く、くわしい内容は **提案書（.mdファイル）を添付** してください。

> ⚠️ 実在の子どもの情報・画面写真は入れないでください。例を出すときは架空のサンプルで。

---

## 1. Discord の本文（コピーして使う）

```
【TRM提案】（タイトル：〇〇を△△できるようにする）
種類：新しい機能 ／ 直してほしいところ ／ 質問 ／ 調べたこと
急ぎ：急ぐ ／ ふつう ／ いつでも
ひとこと：（利用者にとって何がよくなるか、1〜2行）
見た版：（コミットの番号の先頭7文字、または日付）
添付：提案書_〇〇.md
```

## 2. 提案書（添付する .md ファイルの中身）

ファイル名：`提案書_（短いタイトル）_（日付）.md`　例：`提案書_受給者証の読み取り_20261005.md`

```markdown
# 提案書：（タイトル）

- 出した人：（Discordの名前）
- 日付：
- 見た版：（コミットの番号、または日付）
- 種類：新しい機能 ／ 直してほしいところ ／ 質問 ／ 調べたこと

## 1. やりたいこと
（利用者が何に困っていて、これで何がよくなるか。利用者の言葉で）

## 2. 使う場面
（例：夜、子どもが寝たあとに、スマホで受給者証の写真をとって…）

## 3. 変更の案
- 画面：
- データ（src/schema.json の項目）：
- 動き（src/logic.js など）：
- 影響するファイル：

## 4. 決まりとの確認（CLAUDE.md の 3・4）
- [ ] 実在の子どもの情報を使っていない
- [ ] 無料の範囲でできる（有料が必要なら、その理由と代わりの案）
- [ ] Google の権限（スコープ）を増やさない（増やすなら、どれを・なぜ）
- [ ] Discord の通知に医療の情報を載せない
- [ ] 「今は作らないもの」に入っていない

## 5. ほかの案と、選ばなかった理由
（あれば）

## 6. 気になる点・わからない点
（リスク、確かめたいこと、Jean=Summer に決めてほしいこと）

## 7. 出典
（自治体のページ・資料の名前とページ・URLなど。制度や手続きの話のときは必ず）

## 8. コードの案（任意）
（あれば。どのファイルのどこに入れる想定か書く）
```

## 3. 共同開発者の Claude への指示

Claude で **TRM 専用のプロジェクト** を作り、次の 3-1 を「プロジェクトの指示」に入れておくと、新しく会話を始めるたびに同じ前提で相談できます。

### 3-1. プロジェクトの指示に入れる文（最初に1回だけ）

```
このプロジェクトは「たすかReマインド（task-a-remind）」の開発の相談用です。
リポジトリ：https://github.com/jeanjeanjean-sama/task-a-remind（公開）

・相談を始める前に、リポジトリの CLAUDE.md と guide/提案の形.md を必ず読んでください。
　読めないときは、読めなかったと伝えてください（推測で進めないでください）。
・あなたの役目は相談相手と提案書づくりです。GitHubの更新は Jean=Summer が行います。
　コミット・プルリクエスト・Issueの作成はしないでください。
・提案の前に、関係するファイルを実際に読み、読んだ版（コミット番号か日付）を記録してください。
・CLAUDE.md の「必ず守る決まり」に合わない案は、理由と代わりの案を示してください。
・実在の子どもの情報（名前・病名・番号・住所・写真）は扱いません。例は架空のサンプルで。
・説明はやさしい日本語で。
・相談の最後に「提案書にして」と言われたら、guide/提案の形.md の「提案書」の形で
　.md ファイルを作り、あわせて Discord に貼る短い本文（2000文字以内）も出してください。
```

### 3-2. 相談を始めるとき

```
CLAUDE.md と guide/提案の形.md を読んでから、相談に乗ってください。
相談したいこと：（ここに書く）
```

### 3-3. 相談の最後

```
ここまでの内容を提案書にしてください。
・提案書の .md ファイル（ファイル名：提案書_短いタイトル_日付.md）
・Discord に貼る短い本文
決まっていないこと・Jean=Summer に決めてほしいことは「6. 気になる点」に分けて書いてください。
```

できた本文を Discord に貼り、.md ファイルを添付して送ります。

### 3-4. 注意

- Claude が GitHub のページを読めない場合は、関係するファイルを GitHub からダウンロードして添付してください
- Discord への送信は、共同開発者が自分で行います（Claude に直接送らせる必要はありません）
- Claude の設定で「会話を学習に使わせるかどうか」を確認しておいてください

## 4. Jean=Summer が受け取ったあと

1. 本文と提案書を、TRM開発のプロジェクトのスレッドに貼り付け・添付して相談する
2. 採用するものは GitHub の Issue にする（提案書の要点と、決めたことを書く）
3. 結果（採用・一部採用・見送りと理由）を Discord で返す
