# Google版（スプレッドシート＋GAS）の導入手順

Google版では、データは**利用者自身のGoogleドライブのスプレッドシート**に保存されます。開発する人がデータを預かることはありません。

- 必要なもの：Googleアカウント（Gmailのアカウント）、Discordのアカウント
- 費用：かかりません

---

## A. 配布用のスプレッドシートを作る（開発する人が1回だけ）

1. Googleドライブで新しいスプレッドシートを作り、名前を「たすかReマインド」にする
2. メニュー「拡張機能」→「Apps Script」を開く
3. 左の「プロジェクトの設定（歯車）」→「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェック
4. エディタに戻り、次の4つのファイルを作って、リポジトリの `gas/` フォルダの中身をそれぞれ貼り付ける（Releases の `tasuka-remind-gas-*.zip` にも同じ4ファイルが入っています）
   | エディタでのファイル名 | 貼り付けるファイル | 作り方 |
   |---|---|---|
   | `appsscript.json` | `gas/appsscript.json` | 最初からある |
   | `Code.gs` | `gas/Code.gs` | 最初からある（中身を置き換える） |
   | `Shared.gs` | `gas/Shared.gs` | 「＋」→「スクリプト」で `Shared` |
   | `Index.html` | `gas/Index.html` | 「＋」→「HTML」で `Index` |
5. 保存する（Ctrl+S）
6. スプレッドシートに戻り、メニュー「たすかReマインド」→「① 初期設定」を実行して、シートができることを確かめる
7. **架空のデータ以外が入っていないことを確認してから**、共有リンクを作る
   - 「共有」→「一般的なアクセス」を「リンクを知っている全員（閲覧者）」
   - リンクの末尾の `/edit…` を `/copy` に書き換えたものが**配布用リンク**です
     例：`https://docs.google.com/spreadsheets/d/XXXXXXXX/copy`

コマンドで管理したい場合は、Googleの `clasp` を使うと `gas/` フォルダをそのままアップロードできます（[推奨手順の「7-2」](00_推奨手順.md#7-2-新しい版を反映する)）。

> コードを更新しても、すでにコピーした人のスプレッドシートには自動で反映されません。更新版への移り方は [推奨手順の「7-3」](00_推奨手順.md#7-3-すでに使っている利用者への案内) を見てください。

---

## B. 利用者の導入手順

### 1. スプレッドシートをコピーする

1. 配布用リンクを開き、「コピーを作成」を押す
2. 自分のドライブに「たすかReマインド のコピー」ができます（名前は変えてかまいません）

### 2. 初期設定（権限の承認）

1. コピーしたスプレッドシートを開き、少し待つとメニューに「たすかReマインド」が出ます
2. 「たすかReマインド」→「① 初期設定（最初に1回）」
3. 「承認が必要です」→「続行」→ 自分のアカウントを選ぶ
4. **「このアプリは Google で確認されていません」と出たら**
   - 左下の「詳細」→「たすかReマインド（安全ではないページ）に移動」
   - これは「Googleの審査を受けていない、個人が作ったスクリプト」という意味です。このスクリプトは、あなたのドライブの中だけで動き、データを外部に送るのはDiscordへの通知だけです
5. 許可する内容を確認して「許可」
6. 「初期設定が終わりました」と出れば完了です

許可する内容とその理由：

| 表示される内容 | 使う理由 |
|---|---|
| スプレッドシートの参照・編集 | データを保存するため |
| 外部サービスへの接続 | Discordに通知を送るため |
| 自分がいないときの実行 | 毎晩の通知のため（1時間ごとに動き、決めた時刻だけ送る） |
| このアプリで作ったファイルだけの参照・作成 | PDFや書き出しファイルをドライブに保存するため（ほかのファイルは見えません） |

### 3. Discordの準備

1. Discordで自分用のサーバーを作る（左の「＋」→「オリジナルの作成」→「自分と友達のため」）
2. 通知用のチャンネル（例：`#たすか`）の歯車 →「連携サービス」→「ウェブフック」→「新しいウェブフック」
3. 「ウェブフックURLをコピー」
4. スプレッドシートのシート「_設定」の `discordWebhookUrl` の「値」に貼り付ける
5. メニュー「たすかReマインド」→「通知のテスト送信」で、Discordに届くか確かめる
6. スマホのDiscordアプリで、そのサーバーの通知を「すべてのメッセージ」にしておく

家族も通知を受けたいときは、そのDiscordサーバーに家族を招待します。

### 4. スマホで使う画面（Webアプリ）を出す

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」
2. 右上の「デプロイ」→「新しいデプロイ」
3. 「種類の選択」の歯車 →「ウェブアプリ」
4. 設定する
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
5. 「デプロイ」→ 表示された「ウェブアプリのURL」をコピー
6. そのURLをスマホで開き（同じGoogleアカウントでログイン）、「ホーム画面に追加」
7. アプリの「設定」で通知の時刻を確かめ、「保存」

> スマホのブラウザで複数のGoogleアカウントにログインしていると、Webアプリが開けないことがあります。その場合は、使うアカウント以外からログアウトするか、シークレットでないタブで使うアカウントだけにログインしてください。

### 5. 家族と一緒に使う（任意）

1. スプレッドシートを家族のGoogleアカウントと共有する（「編集者」）
2. Apps Scriptで「デプロイ」→「デプロイを管理」→ 編集（鉛筆）→ 次のように変えて「デプロイ」
   - 次のユーザーとして実行：**ウェブアプリケーションにアクセスしているユーザー**
   - アクセスできるユーザー：**Google アカウントを持つ全員**
3. 家族はURLを開き、最初に一度だけ承認（上の2.と同じ画面）をする

この設定では、各自が「自分の権限」で動くため、**スプレッドシートを共有されていない人はURLを知っていてもデータを見られません**。

> ⚠️ 「実行：自分」＋「アクセス：全員」の組み合わせにはしないでください。URLを知った人が誰でもデータを見られてしまいます。

## 通知の内容

| 時刻（初期値） | 内容 |
|---|---|
| 毎晩22時 | 今夜できること／明日の昼にやること／昼にやる日を決めること／期限が近い受給者証・手帳 |
| 毎日12時 | 今日の昼にやること（連絡先の電話番号・受付時間・伝えること） |

- 送る内容がない日は送りません
- 1時間ごとに動くため、通知は設定した時刻の「○時台」に届きます（例：22時台のどこか）
- 通知には病名や医療の内容は載せません。ただし「伝えること・持ち物」に書いた文章は昼の通知に載るので、番号などは書かないでください

## PDFとファイル

- 手順書・サポートブックの印刷画面で「PDFをドライブに保存」を押すと、ドライブのフォルダ「たすかReマインド」に保存されます
- 支援者に渡すときは、ドライブでそのPDFを「共有」→「リンクを知っている全員（閲覧者）」にしてリンクを送ります
- 内容を直したら、PDFを作り直して送り直してください

## 困ったとき

| 症状 | 対処 |
|---|---|
| メニューが出ない | スプレッドシートを再読み込みして、10秒ほど待つ |
| 通知が来ない | 「通知のテスト送信」を試す。届かなければWebhook URLを貼り直す |
| 夜の通知が来ない | その日に送る内容がなかった可能性があります。アプリの「今日」画面を確認 |
| 「スプレッドシートが見つかりません」 | スプレッドシートのメニューから「① 初期設定」をもう一度実行 |
| シートを直接直した | 1行目（英字のキー）と2行目（項目名）は変えないでください。3行目以降は直してかまいません |
