たすかReマインド

プライバシーポリシー

たすかReマインド（task-a-remind）　制定日：2026年9月29日

かんたんに言うと

  • 入力した情報は、あなたの端末と、あなたが選んだ場合はあなた自身のGoogleドライブにだけ保存されます。
  • 開発・運営する人（以下「運営者」）のサーバーはありません。運営者があなたのデータを見ることはできません。
  • Googleアカウントの情報は、ドライブとの同期のためだけに使います。広告・販売・AIの学習などには使いません。

1. このポリシーの対象

このポリシーは、個人の開発者 Jean=Summer が作っている「たすかReマインド」（英字表記：task-a-remind、以下「このアプリ」）に適用されます。このアプリには、次の版があります。

  • かんたん版（Web版）：https://jeanjeanjean-sama.github.io/task-a-remind/
  • かんたん版＋Googleドライブ同期：かんたん版で「Googleでログインして同期を始める」を選んだ場合
  • Google版：利用者が自分のGoogleアカウントに、このアプリのプログラム（Google Apps Script）とスプレッドシートを用意して使う版

2. このアプリで扱う情報と、保存される場所

このアプリには、利用者（主に保護者）が、子どもの情報（呼び名、生年月日、医療的ケアの手順、受給者証の期限、手帳の等級、連絡先など）や、手続きの予定を入力します。「使えるかもしれない制度」の目安も、この情報を使ってあなたの端末の中で計算し、外へは送りません。これらは、次の場所にだけ保存されます。

版保存される場所
かんたん版使っている端末のブラウザの中（localStorage）。インターネットには送られません。
Googleドライブ同期上の端末に加えて、あなた自身のGoogleドライブの「このアプリ専用の見えない場所」（appDataFolder）に、1つのファイルとして保存されます。
Google版あなた自身のGoogleアカウントにあるスプレッドシート。

どの版でも、情報が運営者に送られることはありません。運営者は、利用者の情報を集めたり、保存したり、見たりしません。

3. Googleアカウントのデータの扱い

Googleドライブ同期を使うとき、このアプリはGoogleのログイン画面で、次の2つの許可をお願いします。

お願いする許可使いみち
このアプリ専用のフォルダの読み書き
https://www.googleapis.com/auth/drive.appdata		このアプリのデータファイルを、ドライブの専用の場所に保存し、ほかの端末と同じ内容にする（同期する）ため。このアプリが作ったファイルしか見えません。ドライブにある写真や書類など、ほかのファイルを見ることはできません。
メールアドレスの表示
email		どのGoogleアカウントで同期しているかを、設定画面に表示するため。

使い方の決まり

  • Googleから受け取った情報は、あなたの端末とあなたのドライブの間で、データを同期するためだけに使います。
  • 通信は、あなたのブラウザとGoogleの間で直接行います。運営者のサーバーを通りません。
  • ログインのしるし（アクセストークン）は、ブラウザのそのタブの中（sessionStorage）だけに置き、タブを閉じると消えます。ほかへは送りません。メールアドレスは、表示のためにその端末のブラウザに保存します。
  • Googleから受け取った情報を、売ったり、人に渡したり、広告に使ったりしません。AI（機械学習）のモデルを作ったり改良したりするためにも使いません。お金を貸すかどうかの判断など、信用の評価にも使いません。
  • 運営者が、あなたのGoogleのデータを読むことはありません。

このアプリがGoogle APIから受け取った情報の使用と、ほかのアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

4. 人に渡すこと・つながる先

運営者は、利用者の情報を第三者に渡しません。ただし、このアプリを動かすために、あなたの端末が次のサービスと通信します。

  • GitHub Pages（GitHub, Inc.）：かんたん版の画面を配信しています。画面を開くと、GitHubがアクセスの記録（IPアドレスなど）を残すことがあります。子どもの情報は送られません。
  • Google：Googleドライブ同期やGoogle版を使う場合に、ログインとデータの保存のために通信します。Googleでの扱いは、Googleのプライバシーポリシーに従います。
  • Discord：Google版で通知を設定した場合だけ、あなたが指定したDiscordのチャンネルに、手続きの名前・期限・連絡先を送ります。病名や医療の内容は送りません。

あなたが自分で「書き出し」「印刷・PDF」「カレンダー用ファイル」を作って人に渡した場合、その後の扱いは受け取った人の管理になります。

5. 情報の削除と、許可の取り消し

  • 端末のデータ：ブラウザの設定で、このサイトのデータを消すと削除されます。消す前に「データを書き出す」でバックアップをとっておくと安心です。
  • ドライブのデータ：アプリの「設定」→「同期をやめて、ドライブのデータも消す」で削除できます。または、パソコンのGoogleドライブで「設定」→「アプリの管理」→「たすかReマインド」→「オプション」→「アプリの隠しデータを削除」でも消せます。
  • Googleの許可の取り消し：Googleアカウントの「サードパーティのアプリとサービス」で、「たすかReマインド」へのアクセスを削除できます。
  • Google版のデータ：あなたのスプレッドシートとプログラムを、あなたのGoogleドライブから削除してください。

運営者は利用者の情報を持っていないため、運営者の側で消す作業はありません。

6. クッキー・アクセス解析・広告

このアプリは、アクセス解析や広告のためのクッキー（Cookie）やツールを使っていません。データを端末に保存するために、ブラウザの保存機能（localStorage・sessionStorage）を使います。

7. 安全のために

  • 通信は暗号化（HTTPS）されています。
  • Googleの許可は、同期に必要な最小限（このアプリ専用の場所とメールアドレス）だけにしています。
  • このアプリのプログラムは、GitHubで誰でも確認できます。
  • 端末をなくしたときに備えて、端末の画面ロックを使ってください。

8. 子どもの情報について

このアプリは、保護者や家族が、子どものために情報をまとめることを目的としています。子ども本人がアカウントを作って使うことは想定していません。

9. このポリシーの変更

このポリシーを変えるときは、このページで知らせ、上の日付を新しくします。変更の履歴は、GitHubで見られます。
